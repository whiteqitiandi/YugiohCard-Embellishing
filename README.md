# 秘藏決鬥圖鑑（Arcana Archive）

純單機、個人欣賞用途的遊戲王卡片圖鑑與藝術加工雛型。目前完成：

- 本機 SQLite 圖鑑、跨語言搜尋、密碼萬用字元、卡圖與規則版本切換。
- 卡片圖鑑可在「詳細檢視」與高密度「網格目錄」間切換；目錄支援圖鑑順序、名稱、攻擊力、守備力、等級／階級／LINK、首次發行日及卡片種類排序，並可用方向鍵選擇鄰近卡片、Enter 開啟詳細檢視。
- 獨立的「資料更新中心」：YGOPRODeck 提供卡片結構／發行日／英文名稱，百鴿（YGOCDB）提供中文文字與日文名稱，再以 OpenCC 轉台灣正體。
- 中英日卡名完整性會依發行區域判定：跨 OCG／TCG 發行必須三語齊全；區域限定卡只要求中文及該區語系。
- 可指定 OCG／TCG 的單一發行月份，或續傳更新「截至指定年月（含）的全部卡片」；來源各自節流並保存發行涵蓋進度。
- 獨立的進階篩選視窗：類別、細分、屬性與種族同組多選固定採聯集，只有效果支援納入／排除及聯集／交集。
- 可手動把卡片標記為本機冷門卡，並在篩選與常用條件中設定顯示全部、隱藏冷門或只顯示冷門。
- 仿 Duel Links Chronicle Card 的分層加工實驗室（表面、範圍、邊框、卡名、印章）。
- Electron 原生功能選單與可持久化的介面文字大小設定。
- 卡片創作、牌組工房的導覽與資料邊界已預留，尚未實作。

## 啟動

可直接使用 [`輔助批次檔`](./輔助批次檔) 內的批次檔：

1. 首次執行 `install.bat`。
2. 日常執行 `run.bat`。它會優先使用本專案 Electron；若 binary 尚未快取，可只讀借用 `C:\War3ModelElectron` 的既有 Electron 執行檔。
3. 驗證正式建置執行 `rebuild.bat`。
4. 清除可重建檔案前，先執行 `pure.bat --dry-run` 預覽。

也可在 PowerShell 手動執行：

```powershell
npm install
npm run dev
```

## 更新卡片資料

由左側進入「資料更新中心」，選擇發行地區、年份、月份與更新方式：

- 「指定單一月份」只處理該月。
- 「截至指定年月的全部卡片」會從上次未完成的發行月份／月內位置接續；達到任一來源的單次流量上限便停止，下次可續傳。

YGOPRODeck API v7 負責卡片結構、OCG／TCG 各自發行日、英文名稱與圖片清單；百鴿 API 負責中文卡名、中文效果文與日文名稱，中文並以 OpenCC 轉為台灣正體（屬機器轉換，非官方繁中校訂）。同時在兩區發行的卡必須具備中／英／日名稱；OCG 限定卡要求中／日，TCG 限定卡要求中／英。若任一必要語系缺漏，程式會停在該張並保留續傳位置，不以其他語系冒充完成。卡圖不會在更新時批次下載，而是在實際查看時下載一次並存入本機媒體分片。

兩個來源各有獨立政策：YGOPRODeck 每批 100 張、至少間隔 1 秒、每次執行最多 40 次請求；百鴿每批 100 張、至少間隔 2 秒、每次執行最多 5 次請求／500 張。介面顯示的「完整涵蓋至」是卡片發行日期，不是軟體執行更新的時間。來源規格請見 [YGOPRODeck API Guide](https://ygoprodeck.com/api-guide/) 與 [百鴿 API 文件](https://ygocdb.com/api)。

完整研究、資料來源選擇與階段規劃請見 [`Doc/開發計畫.md`](./Doc/開發計畫.md)。
